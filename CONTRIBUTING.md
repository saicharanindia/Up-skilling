# 🤝 Contributing Guide

This is a personal learning portfolio for the Cognizant Up Skilling program. Documentation improvements and corrections are welcome.

## How to Contribute

1. Fork the repository
2. Create a branch: `git checkout -b docs/improvement`
3. Make documentation changes only
4. Commit: `git commit -m "docs: improve module README"`
5. Open a Pull Request

## ⚠️ Rules

> **DO NOT modify source code files** (`.html`, `.css`, `.js`, `.sql`)

*Thank you for contributing!*
