# 🎨 Module 1 — CSS3

[![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat-square&logo=css3&logoColor=white)](https://developer.mozilla.org/docs/Web/CSS)

> 10 hands-on exercises covering CSS3 from selectors and box model to responsive design and layout control.

---

## 📚 Exercises

| # | Exercise | Key Concepts |
|---|----------|-------------|
| 1 | Why CSS | Inline vs internal vs external CSS |
| 2 | CSS Syntax and Comments | Selectors, properties, values, /* comments */ |
| 3 | Selectors Playground | Class, ID, attribute, pseudo selectors |
| 4 | Color and Background Styling | Colors (hex, rgb, hsl), gradients, background images |
| 5 | Typography Fonts and Text | Google Fonts, font-family, font-size, text-align |
| 6 | Link and List Styling | :hover, :active, :visited, list-style |
| 7 | Table Styling | border-collapse, nth-child, zebra stripes |
| 8 | Box Model and Layout Control | margin, padding, border, width, height, box-sizing |
| 9 | Multiple Columns in Text | column-count, column-gap, column-rule |
| 10 | Responsive Web Design | Media queries, breakpoints, mobile-first |

## 🎯 Learning Objectives

- ✅ Apply CSS styling using selectors and specificity
- ✅ Understand and control the CSS box model
- ✅ Style typography with custom fonts
- ✅ Create responsive layouts using media queries
- ✅ Use advanced CSS features like gradients and multi-column layout
