# 🌐 Module 1 — HTML5

[![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=flat-square&logo=html5&logoColor=white)](https://developer.mozilla.org/docs/Web/HTML)

> 10 hands-on exercises covering HTML5 from basic structure to advanced APIs — forms, multimedia, geolocation, and localStorage.

---

## 📚 Exercises

| # | Exercise | Key Concepts |
|---|----------|-------------|
| 1 | HTML5 Base Template | Doctype, charset, viewport meta, semantic structure |
| 2 | Navigation and Linking | `<nav>`, `<a>`, href, internal/external links |
| 3 | Welcome Message | Headings h1-h6, paragraphs, semantic elements |
| 4 | Image Gallery | `<img>`, `<figure>`, `<figcaption>`, alt attribute |
| 5 | Event Registration Form | `<form>`, input types, required, placeholder |
| 6 | Event Feedback | `<textarea>`, `<select>`, radio, checkbox |
| 7 | Video Invite | `<video>`, controls, autoplay, poster |
| 8 | Saving User Preferences | localStorage.setItem / getItem / removeItem |
| 9 | Geolocation | navigator.geolocation, getCurrentPosition |
| 10 | Debugging with Chrome DevTools | Elements panel, Console, Network tab |

---

## ▶️ How to Run

```bash
# Open any exercise folder
# Double-click index.html to open in browser
# Or right-click → Open with Live Server (VS Code)
```

---

## 🎯 Learning Objectives

- ✅ Write valid, semantic HTML5 documents
- ✅ Build accessible web forms with proper input types
- ✅ Embed multimedia (video, audio, images) correctly
- ✅ Use the localStorage API for client-side persistence
- ✅ Access device geolocation via browser API
- ✅ Debug web pages using Chrome DevTools
