# 🎨 Module 1 — Bootstrap 5

[![Bootstrap](https://img.shields.io/badge/Bootstrap-5-7952B3?style=flat-square&logo=bootstrap&logoColor=white)](https://getbootstrap.com/)

> 10 exercises building responsive, mobile-first web UIs using Bootstrap 5's grid system, flexbox utilities, and components.

---

## 📚 Exercises

| # | Exercise | Key Concepts |
|---|----------|-------------|
| 1 | Setting Up Bootstrap 5 | CDN link, local setup, starter template |
| 2 | Bootstrap Structure and Files | container, row, col, Bootstrap anatomy |
| 3 | Responsive Grid Layout | 12-column grid, breakpoints, fluid layout |
| 4 | Column Layouts and Grid Classes | col-sm, col-md, col-lg, col-xl |
| 5 | Alignment and Reordering | offset, order, align-self |
| 6 | Responsive Flexbox Utilities | d-flex, justify-content, align-items, flex-wrap |
| 7 | Typography | Display headings, text utilities, alignment |
| 8 | Forms | Form controls, labels, validation, form-row |
| 9 | Buttons | Variants (primary, secondary), sizes, states |
| 10 | Navbars and Navigation | Navbar, collapse, toggler, responsive nav |

---

## ▶️ How to Run

```bash
# Open index.html in Chrome
# Resize browser window to see responsive behavior
# Use Chrome DevTools → Toggle device toolbar (Ctrl+Shift+M)
```

---

## 🎯 Learning Objectives

- ✅ Use Bootstrap 5 CDN and local setup
- ✅ Build responsive layouts with the 12-column grid
- ✅ Apply flexbox utilities for component alignment
- ✅ Style typography and forms with Bootstrap classes
- ✅ Build responsive navigation with Navbar component
- ✅ Understand Bootstrap breakpoints (xs, sm, md, lg, xl, xxl)
