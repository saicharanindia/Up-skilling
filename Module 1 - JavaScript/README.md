# ⚡ Module 1 — JavaScript ES2023

[![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=flat-square&logo=javascript&logoColor=black)](https://developer.mozilla.org/docs/Web/JavaScript)

> 10 exercises covering modern JavaScript — from basics and DOM manipulation to async programming with Promises and async/await.

---

## 📚 Exercises

| # | Exercise | Key Concepts |
|---|----------|-------------|
| 1 | Basics and Setup | Variables, data types, console.log, script tag |
| 2 | Syntax Data Types and Operators | let/const/var, typeof, arithmetic, comparison |
| 3 | Conditionals Loops and Error Handling | if/else, switch, for/while, try/catch/finally |
| 4 | Functions Scope Closures HOF | Arrow functions, closures, map, filter, reduce |
| 5 | Objects and Prototypes | Object literals, this, prototype chain, classes |
| 6 | Arrays and Methods | Array methods, spread operator, destructuring |
| 7 | DOM Manipulation | querySelector, innerHTML, createElement, classList |
| 8 | Event Handling | addEventListener, event object, delegation |
| 9 | Async JS Promises Async Await | Promise, fetch API, async/await, error handling |
| 10 | Modern JavaScript Features | Template literals, destructuring, modules, optional chaining |
