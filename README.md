## 📖 About This Repository

This repository contains **complete hands-on solutions and exercises** from the **Cognizant Up Skilling Program** for the **DotNet Full Stack Engineer (FSE)** track.

The program covers the foundational and intermediate technologies required for full-stack development — from web fundamentals (HTML5, CSS3, JavaScript) to UI frameworks (Bootstrap 5, jQuery), relational databases (MySQL), and backend data access (C# ADO.NET).

### 🎯 Purpose

| Goal | Description |
|------|-------------|
| 🎓 Learning | Master front-end fundamentals and database programming |
| 💼 Portfolio | Showcase web development and database skills |
| 📚 Reference | Personal knowledge base for full-stack development |
| 🏆 Career | Demonstrate readiness for enterprise full-stack roles |

### 👥 Who This Repository Is For

- Software engineers enrolled in Cognizant Up Skilling (DotNet FSE)
- Web developers brushing up on HTML5, CSS3, and JavaScript fundamentals
- Developers learning SQL with MySQL for enterprise applications
- Recruiters evaluating full-stack web development proficiency

## 🎤 Interview Preparation

<details>
<summary><strong>🟠 HTML5 Questions</strong></summary>

- What is the difference between `<div>` and semantic elements like `<section>`, `<article>`, `<aside>`?
- What are the new input types in HTML5?
- How does the Geolocation API work?
- What is localStorage vs sessionStorage vs cookies?
- What is the difference between `<script>` with `defer` vs `async`?

</details>

<details>
<summary><strong>🔵 CSS3 Questions</strong></summary>

- What is the CSS Box Model?
- Explain the difference between `position: relative`, `absolute`, `fixed`, `sticky`.
- What is specificity in CSS?
- How do media queries work for responsive design?
- What is the difference between Flexbox and CSS Grid?
- What is the difference between `em`, `rem`, `px`, `%` units?

</details>

<details>
<summary><strong>🟡 JavaScript Questions</strong></summary>

- What is the difference between `var`, `let`, and `const`?
- Explain closures in JavaScript.
- What is the event loop and how does async JS work?
- What is the difference between `==` and `===`?
- Explain `Promise`, `async/await`, and error handling.
- What is hoisting in JavaScript?
- What is the difference between `null` and `undefined`?

</details>

<details>
<summary><strong>🟣 Bootstrap 5 Questions</strong></summary>

- How does Bootstrap's 12-column grid system work?
- What is the difference between `container`, `container-fluid`, and `container-{breakpoint}`?
- How do you make a layout responsive using Bootstrap?
- What are Bootstrap's breakpoints?
- How do you customize Bootstrap using utility classes?

</details>

<details>
<summary><strong>🟢 SQL / MySQL Questions</strong></summary>

- What is the difference between `INNER JOIN`, `LEFT JOIN`, and `RIGHT JOIN`?
- What is the difference between `WHERE` and `HAVING`?
- Explain `GROUP BY` with an example.
- What are aggregate functions?
- What is a subquery? Give an example.
- What is normalization? Explain 1NF, 2NF, 3NF.
- What is the difference between `DELETE`, `TRUNCATE`, and `DROP`?

</details>

<details>
<summary><strong>🔴 C# ADO.NET Questions</strong></summary>

- What is ADO.NET and how does it differ from Entity Framework?
- What is `SqlConnection`, `SqlCommand`, and `SqlDataReader`?
- What is the difference between `ExecuteReader`, `ExecuteScalar`, and `ExecuteNonQuery`?
- How do you prevent SQL injection using ADO.NET?
- What is a connection pool in ADO.NET?
- What is `DataSet` vs `DataReader`?

</details>
