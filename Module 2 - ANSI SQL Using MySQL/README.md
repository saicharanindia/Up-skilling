# 🗄️ Module 2 — ANSI SQL Using MySQL

[![MySQL](https://img.shields.io/badge/MySQL-8.0-4479A1?style=flat-square&logo=mysql&logoColor=white)](https://www.mysql.com/)
[![SQL](https://img.shields.io/badge/ANSI-SQL-orange?style=flat-square)](https://www.iso.org/standard/63555.html)

> Relational database fundamentals using ANSI SQL standard with MySQL — covering DDL, DML, joins, aggregations, subqueries, and constraints.

---

## 📚 Topics Covered

| Category | Concepts |
|----------|----------|
| **DDL** | CREATE TABLE, ALTER TABLE, DROP TABLE, TRUNCATE |
| **DML** | SELECT, INSERT, UPDATE, DELETE |
| **Joins** | INNER JOIN, LEFT JOIN, RIGHT JOIN, CROSS JOIN |
| **Aggregations** | COUNT, SUM, AVG, MIN, MAX, GROUP BY, HAVING |
| **Subqueries** | Nested SELECT, correlated subqueries, IN, EXISTS |
| **Constraints** | PRIMARY KEY, FOREIGN KEY, UNIQUE, NOT NULL, CHECK |
| **Sorting** | ORDER BY ASC/DESC, LIMIT, OFFSET |
| **String Functions** | CONCAT, UPPER, LOWER, SUBSTRING, LENGTH |
| **Date Functions** | NOW(), CURDATE(), DATE_FORMAT(), DATEDIFF() |

## 🎯 Learning Objectives

- ✅ Create and manage database schemas and tables
- ✅ Write SELECT queries with filtering and sorting
- ✅ Join multiple tables using various JOIN types
- ✅ Aggregate data using GROUP BY and HAVING
- ✅ Write subqueries for complex data retrieval
- ✅ Apply database constraints for data integrity

4. What is the difference between `DELETE` and `TRUNCATE`?
5. What are indexes and when should you use them?
6. What is a subquery vs a JOIN — when to use each?
7. What are database constraints and why are they important?
